# 0.2.0-rc.2 预发布版本

[English](../../en/releases/0.2.0-rc.2.md) · [首页](../../../README.md)

日期：2026-09-23。`0.2.0-rc.2` 已通过不可变标签、GitHub Release、npm Trusted Publishing 和独立 Demo 部署；npm `next` 与线上 Demo 已对应 rc.2，稳定 `latest` 仍为 0.1.0。完整回执见[发布报告](../../../reports/2026-09-23-release-rc2/README.md)。

## 新增内容

- 新增独立 `web-sdk-pp-tracking/motion` 子入口，接收相邻 `ImageData`/`VideoFrame`，比较纯平移、稀疏光流和特征匹配。
- 新增 `/motion.html` 实验页、JSON 导出、状态复位和固定 seed 合成基准；不读取检测框，不加载模型，不自动接入 BoT-SORT。
- 质量失败返回不含矩阵的 `failed` 回执；输入结构错误抛出 `MotionEstimateError`。稀疏光流使用更保守的 `0.8` 置信度门限，周期纹理和搜索范围外候选会明确失败。

## 本地证据与限制

Windows 11、Node 24.16、Chromium 153、CPU/main 的合成基准记录在[运动估计报告](../../../reports/2026-09-23-motion-estimation/README.md)。640×360 的 Node p95 为纯平移 15.5 ms、稀疏光流 71.8 ms、特征匹配 191.1 ms；对应成功率为 41.7%、33.3%、41.7%。这些指标包含复杂运动、低纹理、重复纹理和超范围运动的预期失败，不能外推到手机、Worker、GPU/NPU、Safari、Firefox、视频或摄像头。

BoT-SORT、ByteTrack 默认策略、ReID 子入口和线上版本边界不变。若要自动接入 BoT-SORT，必须另写设计并补充真实合法帧、浏览器耗时和跟踪框误差证据。
