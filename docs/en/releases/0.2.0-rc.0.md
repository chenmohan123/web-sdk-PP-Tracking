## Migration from0.1

`createTracker()` still defaults to ByteTrack CPU/main, preserving update/reset/dispose and box input. Select OC-SORT explicitly with `algorithm: 'ocsort'`. DeepSORT requires `algorithm: 'deepsort'`, a consistent FeatureSpace and matching per-frame/per-detection appearance vectors. Optional `web-sdk-pp-tracking/reid` generates512D vectors from caller-provided person images and boxes; it provides no detector or video/camera scheduler. Changing model, feature space, source or backend requires session disposal and dependent tracking reset. Track IDs are not personal identities.

Algorithms are independent implementations based on the ByteTrack, OC-SORT and Deep SORT papers under Apache-2.0. Noise, millisecond lifecycle and width/height state differ from paper implementations; see [algorithm details](../algorithm.md) and NOTICE. No official-port or value-level compatibility claim is made.

## Installation and model

Install the explicit RC, or a tarball built from source:

```sh
npm install web-sdk-pp-tracking@0.2.0-rc.0
# Install only when using the optional model subpath:
npm install onnxruntime-web@1.27.0
```

The root has no production dependencies; ORT1.27.0 remains an optional peer. Even after explicitly importing `./reid`, the engine loads only during load. Association always uses CPU/main; extraction separately selects WASM/main or WebGPU/main without silent fallback. Five algorithm timing fields and model download/integrity/session/decode/preprocess/inference/postprocess timings are reported separately; each totalMs is measured independently.

Model `pplcnet-reid-fp32` remains0.1.0, FP32/ONNX opset17,33,704,835 bytes, SHA-256 `24d347f47405bb1bd24fd582783507edbcb16571d2e845d0528b0ad7856336e4`. Default ModelScope revision is `dc3d9f7a97be4033e654525f0e9d3fbd5eaf7c9b`; optional Hugging Face revision is `02c299b5b5618315fc754002b7ea7c95c95e8a82`. Source failures do not silently switch providers. Weights are excluded from npm. Distribution relies on the official repository Apache-2.0 license; see the [model card](../../../models/pplcnet-reid/0.1.0/README.en.md) for weight-specific authorization and training-data disclosure limits.

## Evidence and limitations

The [2026-09-21 real-image evaluation](../../../reports/2026-09-21-mot-reid/README.en.md) measured0.2.0-alpha.0 commit0194ea5 over seven sequences/5316 frames/67639 detections. ByteTrack, OC-SORT and DeepSORT+PPLCNet IDF1 were48.2922%,48.4107%,45.4637%. Selected DeepSORT metrics do not establish overall improvement. No appearance-disabled ablation allows attribution solely to the model. ByteTrack stays default and person ReID remains experimental. These are not test-set rankings, phone performance or end-to-end video speed.

RC production runtime changes only version strings/type literals; mathematics, weights, preprocessing, thresholds and API semantics are unchanged. Historical reports/hashes are preserved and the full5316-frame evaluation was not repeated. RC requires its own tarball and browser evidence; historical build hashes are not RC measurements. See dated [compatibility](../compatibility.md).390px is a desktop viewport; Safari, Firefox, real phones, Workers and NPU are unverified. Demo separates state reset, cancellation and model cleanup; language switching preserves state.
