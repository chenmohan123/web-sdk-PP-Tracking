# PPLCNet ReID 图像输入验证协议

日期：2026-09-20。承接用户确认的下一阶段：固定图像预处理、补齐来源说明，为同包可选 ReID 接入确定接口与标准。本轮是可行性研究，探针不作为 npm API 或 Demo 发布。

## 预先固定的协议

1. 使用上轮已转换 ONNX SHA-256 `24d347f47405bb1bd24fd582783507edbcb16571d2e845d0528b0ad7856336e4`，不训练、不改权重、不调量化。32位输入 `[1,3,192,64]`，512维输出。
2. 独立于上轮02/04的五个序列为 MOT17-05/09/10/11/13-FRCNN。每段固定帧1/31/61/91/121/151，复用上轮完整框、mark=1、class=1、visibility>=0.7、w>=16、h>=48的规则；每段第1帧图库、后续相同身份查询。列出全部序列（包括图库或查询为空），不据结果挑选数据。只本地研究，不分发原图/完整GT。
3. 同时测量正常RGB/BGR的OpenCV INTER_LINEAR路径与下面的确定性float双线性路径。原先RGB为候选；如独立序列的宏平均Rank-1低于BGR，明确保留通道选择不确定性，不把一次研究变成通用质量保证。不在本轮修改0.2默认关联阈值；报告距离0.1/0.2/0.3/0.4诊断，不从评测数据中挑选最佳阈值。
4. 确定性预处理候选：输入已解码、sRGB、非预乘RGBA8、宽高正整数，各<=8192且总像素<=16,777,216；数据长度严格等于w*h*4。只接受Uint8Array/Uint8ClampedArray，拒绝共享缓冲。API不解码JPEG，不处理EXIF，调用者须先落实图像方向。
5. box={x,y,width,height}为0起点浮点像素框，四值有限，宽高>0且求和有限。先与图像范围相交，左/上floor，右/下ceil；若相交为空即拒绝。输出固定64x192，无转置/letterbox，half-pixel坐标，边界钳位到裁剪像素；双线性在JS/Python float64进行，保持RGB顺序。非不透明像素在插值前按非预乘颜色与白底合成，计算p=(c*a+255*(255-a))/255，不额外取整；归一化((p/255)-mean)/std后仅在最终写入时转FP32。均值0.485/0.456/0.406，std0.229/0.224/0.225。
6. Python独立向量化参考与Node/Chromium中的JS实现：同一RGBA/框下，张量最大绝对差<=2e-6；每个输出长度36864，全部有限。由Python参考张量的Paddle静态FP32输出对比浏览器自预处理后的WASM/WebGPU向量：maxAbs<1e-3且cosineDistance<1e-5，失败不得事后放宽。
7. 测试非方形、分数框、越界、1像素、透明白底、颜色/方向、不可变输入及非法输入；先跑失败测试再写像素实现。真实验证按每序列每预定帧最小ID的一条有效样本选取，样本不足如实记录；人工边界图另行覆盖。
8. 为区分解码差异，从Python已解码像素生成无损PNG，浏览器createImageBitmap/Canvas只在原尺寸取像素；要求PNG路径RGBA与原始RGBA完全一致。JPEG直接解码只做另列诊断，不能用色彩/缩放不一致掩盖数值验收失败。禁止用Canvas drawImage缩放作为固定特征空间定义。
9. 记录实际ORT GPUDevice，禁用CPU EP fallback；CPU为WASM单线程，basic图优化。计时分开预处理、推理、归一化、总耗时。仅本机桌面Chromium，不泛称所有浏览器、手机、摄像头或视频通过。
10. 来源说明补齐官方根README/许可/配置/具体checkpoint与转换哈希，区分代码根许可、具体权重声明与训练数据条件；证据未覆盖的字段明确未知，不伪造许可结论。不上传模型、不执行GitHub/npm远程修改。
11. 按结果给出同包可选入口、特征空间身份、缓存、取消/释放及混合manifest的具体设计；实际产品接入前才实施标准版本/schema/checker演进，不能绕过1.2.0算法/模型互斥规则。保留旧报告、旧三算法runtime及用户原有工作区改动。

## 运行后偏离与反例记录

独立审查指出原第8条“PNG路径RGBA完全一致”未区分透明图，初次脚本却跳过了transparent样本的PNG路径。保留原门槛，不把跳过写成全面通过：实际33组PNG仅覆盖不透明像素；34组raw RGBA包括透明像素，仅证明已解码像素到张量的规则。补充彩色透明/半透明/低alpha PNG诊断后，Chromium Canvas返回的RGBA有7/16个通道字节变化，最大差247，原任意RGBA透明PNG逐字节一致目标失败。该反例以`decode-diagnostics.json`保存，生产首版仅接受已经解码的RGBA，不声称PNG解码等价；后续如要接收图片文件须单独设计透明度/颜色解码契约。
